Free Brazilian CEP Validator — one or in bulk

Need to validate Brazilian CEPs or check an entire list at once? This free online CEP validator also works as a CEP checker and allows you to query from a single CEP to hundreds simultaneously. Paste CEPs in the field — separated by line, comma or space — or import an Excel spreadsheet with CEPs in the first column. The tool queries each CEP against the ViaCEP database and returns street, neighborhood, city, state and IBGE code in seconds.
